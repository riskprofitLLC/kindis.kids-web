# План разработки клиентской части — kindis.kids

> **Статус на 15.11.2026:** этапы 0–6 реализованы + карта каталога (MapLibre,
> OSM-тайлы) и фильтр по региону; тесты: 331 спеков в 63 файлах, покрытие
> строк 46.35% (домен и api-клиент — 100%). lint / typecheck / build / test
> зелёные, каталог、карточка、страница продавца，корзина и оформление заказа
> проверены в браузере против живого API `http://localhost:3100/api/v1`.
> Все шесть этапов закрыты：lint / typecheck / build / test зелёные.
> Бэкенд (`server/`) — этапы 0–2 по его `PLAN.md` + каталог и корзина
> с заказами (этапы 3–4 сервера).

Стек: React 19 + Vite 8 + TypeScript + Tailwind CSS 4 + shadcn/ui +
TanStack Query 5 + Zustand 5 + React Router 7 + React Hook Form + Zod 4.
Платежи и деплой — вне текущего скоупа.

Мобильные приложения (Android/iOS) — в планах. Стратегия: React Native + Expo
с общим TypeScript-ядром (типы, Zod-схемы, API-клиент, Query, Zustand).
Поэтому доменный слой сразу держим без DOM и React-специфики.
AngularJS не рассматриваем (EOL 31.12.2021); Angular 2+ — только если мобильный
продукт станет первичным, что противоречит плану (SEO-каталог, WCAG 2.1 AA).

## Структура каталогов

```
src/
  app/            -- провайдеры, роутер, layout'ы
  pages/          -- по одной папке на роут
  widgets/        -- крупные блоки (шапка, сайдбар каталога, мини-корзина)
  features/       -- фичи (auth, cart, product-form, order-flow)
  entities/       -- типы и API-модели домена
  shared/
    ui/           -- переиспользуемые компоненты shadcn + свои (web-only)
    api/          -- http-клиент, эндпоинты
    domain/       -- типы, Zod-схемы, бизнес-правила (без DOM и React)
    lib/          -- утилиты, форматирование цены и даты
    config/       -- константы, роуты
```

`shared/domain` и `shared/api` — общие с будущим React Native-приложением.
`shared/ui`, `app/`, `pages/`, `widgets/` — web-only.
