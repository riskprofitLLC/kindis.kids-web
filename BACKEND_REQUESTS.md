# Запросы веб-клиента к бэкенду

Документ для команды бэкенда: эндпоинты, которых фронтенду не хватает прямо сейчас.
Общие правила: успех завёрнут в `{ "data": ..., "traceId": "..." }`, ошибки приходят как
`{ "message", "code", "fields" }` со статусом 4xx/5xx, авторизация —
`Authorization: Bearer <accessToken>`.

## GET /users/me и PATCH /users/me

- Зачем: профиль родителя в кабинете (имя, телефон, город).
- GET /users/me -> { data: { id, email, fullName, phone, city } }
- PATCH /users/me тело: { fullName?, phone?, city? } -> тот же объект.
- Статус: эндпоинтов нет на бэкенде, кабинет показывает понятное «недоступно».
